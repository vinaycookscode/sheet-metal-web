# Typography

The library uses **Inter** for UI text and **JetBrains Mono** for code,
loaded from Google Fonts. The system stack is a fallback only — the
font is not optional.

```scss
$font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI',
              Roboto, Helvetica, Arial, sans-serif;
$font-mono:   'JetBrains Mono', 'SF Mono', 'Fira Code', Consolas, monospace;
```

The body scale runs **11 → 40 px** with the default control / body size
at **13 px** — denser than consumer apps, matched to data-heavy
dashboards.

Only those four weights are loaded — they cover every UI need without
inflating the font payload.

## Numerics

Tables, KPI cards, and timestamps use `font-variant-numeric:
tabular-nums` so columns of numbers line up at fixed-width.

<div style={{ fontFamily: 'Inter', fontVariantNumeric: 'tabular-nums', fontSize: 20, fontWeight: 600 }}>
  <div>1,234,567.89</div>
  <div>0,000,000.00</div>
</div>
