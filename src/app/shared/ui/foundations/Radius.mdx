# Radius

Radii are sharpened compared to consumer / iOS conventions — closer to
Linear and Stripe than to Apple.

<div style={{ display: 'grid', gridTemplateColumns: 'repeat(4, 1fr)', gap: 16 }}>

    </div>
  ))}
</div>

## Usage map

| Element | Radius |
|---|---|
| Inline controls (input, button, select, badge bar) | `--radius-md` (8px) |
| Tags, chips, pagination buttons | `--radius-sm` (6px) |
| Cards, panels, dialogs, modal panels | `--radius-md` / `--radius-lg` |
| Avatars (circle), status dots, pills, toggles | `--radius-full` |

Avoid mixing `--radius-lg` (12px) and `--radius-md` (8px) in the same
visual group — radius should compound consistently across nested
elements (e.g. a card with `--radius-md` should contain inputs with
`--radius-sm`, *not* equal or larger radii).
