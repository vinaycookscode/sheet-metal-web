# Spacing

A **4px-base scale**. Every margin, padding, and gap in the library is
a token — no magic numbers in component code.

## Layout grid

| Token | Value | Use |
|---|---|---|
| `--sidebar-width` | 248px | App sidebar |
| `--topbar-height` | 56px  | App topbar |

## Density philosophy

- **Compact controls** — 28px height, for table toolbars and dense layouts
- **Default controls** — 36px height, for forms and standard pages
- **Spacious controls** — 44px height, for auth screens and CTAs

These map onto `--gw-control-surface` in
[`shared/ui/forms/_forms.scss`](?path=/story/forms-input--basic) and
propagate to every input + button.
