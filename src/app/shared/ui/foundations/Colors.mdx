# Color

The GotWell palette is rooted in a single restrained enterprise blue
(`#2563EB`). Semantics (success / warning / danger / info) are 10–15%
desaturated from their iOS-classic equivalents to read calmer at
data-density.

All colors are exposed as CSS custom properties so they swap cleanly
between light and dark themes.

## Dark theme

The same semantic tokens map to lifted hues with heavier shadows to
register on dark surfaces. Activate by setting
`data-theme="dark"` on `<html>` or any container.

```scss
:root[data-theme='dark'] {
  --color-primary:   #3B82F6;
  --surface-page:    #09090B;
  --surface-card:    #18181B;
  --text-primary:    #FAFAFA;
  --border:          #27272A;
  /* …full set in src/styles/_tokens.scss */
}
```
