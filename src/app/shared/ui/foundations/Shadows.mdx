# Shadows

GotWell uses **Linear-style elevation** — a tight ring + soft glow
instead of the heavy drop shadows common to iOS / Material. The ring
defines the surface, the glow hints depth.

## Usage map

| Token | Use |
|---|---|
| `--shadow-xs` | Hairline-only — inline inputs, default cards, table edges |
| `--shadow-sm` | Toolbars, sticky headers, default cards lifted from page |
| `--shadow-md` | Dropdowns, popovers, hover cards |
| `--shadow-lg` | Combobox panels, multi-select panels, toasts |
| `--shadow-xl` | Dialogs, drawers, peak overlays |
| `--shadow-focus` | Universal keyboard focus ring (3px outer ring in primary tint) |

## Dark theme

In dark theme the same tokens use heavier opacity to register on dark
surfaces. The ring becomes a light hairline; the glow goes to true
black.
